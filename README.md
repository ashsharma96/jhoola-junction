# Jhoola Junction Studio — public pages

Home page, privacy policy and terms of use for Jhoola Junction Studio, the private production
tool behind the [Jhoola Junction](https://www.youtube.com/@Jhoola_Junction) YouTube channel.
Published with GitHub Pages. No code, scripts, cookies or analytics: plain HTML and CSS.

- `index.html`: home page, with the official "Developed with YouTube" logo (unmodified, loaded
  from developers.google.com, linked to the channel)
- `privacy.html`: privacy policy (YouTube Developer Policies III.A)
- `terms.html`: terms of use
- `mithu.svg`: Mithu, the channel's original character

Keep the wording in step with the swarm's `docs/COMPLIANCE.md` §3.4 and decision D57.
